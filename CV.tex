\textbf{面向长程 SWE Agent 的 Agentic RL 研究} \hfill 2026.04 -- 至今 \titlebreak
\textit{SWE Agent / RL Post-training}
\begin{itemize}
  \item \textbf{Trajectory Filtering：}针对长程 Agent rollout 质量参差问题，借鉴 LLM-as-Verifier 在 test-time scaling（TTS）中的候选筛选思路，将 verifier 用于 training-time 数据构造，对轨迹进行质量评估与二次筛选，保留高质量样本构造离线 preference data。
  \item \textbf{Step-level Preference：}针对整轨迹难以进行细粒度偏好学习的问题，利用 State--Action Tree（SAT）定位轨迹分叉点并构造共享前缀；结合 OPSD re-decision，在同一前缀下由当前 policy 使用特权信息重新决策生成 chosen action，与原分支动作构造 step-level preference pair 进行 DPO 优化。
  \item \textbf{GRPO Credit：}基于 SkyRL + Mini-SWE-Agent 搭建 $K=8$ on-policy rollout、Docker sandbox 与 SWE harness，在 Mixed408 上使用 4$\times$A800 完成 3,264 条 rollout / 51 个优化步；针对 outcome-only GRPO 将 trajectory-level advantage 广播至整条轨迹带来的粗粒度 credit，探索使用 verifier 或任务反馈构造辅助 credit signal，并按 turn/token 进行时序路由；在 held-out SWE-bench Verified500 上统一评测。
\end{itemize}

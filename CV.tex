\section{\makebox[\widthof{\faCode}][c]{\color{CVBlue}\faCode}\ 科研与项目经历}
\textbf{面向长程 SWE Agent 的 Agentic RL 研究} \hfill 2026.04 -- 至今 \titlebreak
\textit{SWE Agent / RL Post-training}
\begin{itemize}
  \item \textbf{Trajectory Filtering：}针对长程 Agent rollout 质量参差问题，借鉴 LLM-as-Verifier 在 test-time scaling（TTS）中的候选筛选思路，将 verifier 用于 training-time 数据构造，对轨迹进行质量评估与二次筛选，保留高质量样本构造离线 preference data。
  \item \textbf{Step-level Preference：}针对整轨迹难以进行细粒度偏好学习的问题，利用 State--Action Tree（SAT）定位轨迹分叉点并构造共享 prefix；结合 OPSD re-decision，在同一 prefix 下由当前 policy 利用 privileged information 重新决策生成 chosen action，与原分支 action 构造 step-level preference pair 进行 DPO 优化。
  \item \textbf{GRPO Credit：}基于 SkyRL + Mini-SWE-Agent 搭建 on-policy rollout、Docker sandbox 与 SWE harness，在 Mixed408 上完成 outcome-only GRPO 训练实验；针对 trajectory-level advantage 广播至整条轨迹带来的粗粒度 credit，探索基于 verifier 与 task-driven feedback 构造 auxiliary credit signal，并结合 temporal credit routing 分配至关键 turn/token；在 held-out SWE-bench Verified500 上统一评测。
\end{itemize}

\section{\makebox[\widthof{\faFlask}][c]{\color{CVBlue}\faFlask}\ 科研成果}
\textbf{ASE 2026 Tool Demo Paper（CCF-A，录用）—— SmellCC：LLM 自动代码异味重构工具}
\begin{itemize}
  \item \textbf{方法：}构建面向 Top-10 Python code smells 的三阶段自动重构流程：\textit{Smell Detection \& Context Extraction} $\rightarrow$ \textit{LLM-based Refactoring} $\rightarrow$ \textit{Response Parsing \& Application}；其中 Context Slicer 基于 SonarLint diagnostic 定位，通过 AST 等方式扩展至完整函数级 semantic scope，并结合 smell-specific CoT/few-shot prompting 生成 refactoring patch。
  \item \textbf{评测：}在 50 个具备可执行 test suites 的 CodeSearchNet-Python 项目上评估 15,994 个 code smell instances，取得 \textbf{96.8\% smell remediation rate} 与 \textbf{91.3\% functional correctness}；前者衡量 smell elimination，后者通过 regression tests 衡量 behavior preservation。
  \item \textbf{工程增强：}在论文原型基础上实现 review-before-apply workflow：通过 VS Code native diff 展示 LLM-generated patch，并在 Apply 前进行 change-risk analysis 与 syntax validation；Apply 后结合 Sonar re-validation 与 guarded undo，支持 patch 的 pre-apply review、post-apply validation 与 safe rollback。
\end{itemize}
